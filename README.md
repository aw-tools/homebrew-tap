# aw-tools/homebrew-tap

Homebrew tap for [`aw`](https://github.com/aw-tools/aw-cli), which provisions
and reports on reproducible multi-repository agentic workspaces.

```sh
brew install aw-tools/tap/aw-cli
```

The formula is named `aw-cli`, after the project, and installs a command called
`aw`. It installs the prebuilt release archives, verified against the
checksums published with each release. Apple silicon and Intel macOS are
covered, along with x86-64 Linux.

Issues and changes to `aw` itself belong in
[`aw-tools/aw-cli`](https://github.com/aw-tools/aw-cli). This repository holds
the formula and nothing else.
